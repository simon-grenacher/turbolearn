# TurboLearn

Lern-App für Englisch, Deutsch, NMG und Mathematik (3. Klasse).

App: https://simon-grenacher.github.io/turbolearn/

## Aufbau
- `src/app.html`: Quellcode der App (Inhalte, Spiele, Design)
- `src/cars/`: Autobilder der Garage
- `build.py`: erzeugt daraus die eigenständige `index.html` (Bilder eingebettet)
- `index.html`: die veröffentlichte App (GitHub Pages)

Spielstand und PIN liegen nur im Browser des jeweiligen Geräts (localStorage).
